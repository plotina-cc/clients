# Релизы Plotina: каденс, гейты и откат

«Каденс» — это ритм выпуска релизов. Мы выпускаем **раз в неделю** (по четвергам),
плюс внеплановый hotfix, если в проде найден блокирующий баг. Изменения копятся в
`main`, CI собирает **candidate**, но апдейтер его не видит, пока релиз не подтверждён.

## Поток

1. Правки идут в `main` маленькими коммитами; на каждый коммит CI собирает
   candidate-артефакты и манифест обновления, но **не публикует** их.
2. В четверг собирается релизный тег `v<base>-plotina-<client>.<N>`.
3. Гейты (см. ниже) должны быть зелёными.
4. Candidate ставится на телефон и десктоп владельцем, проверяется вручную.
5. Только после подтверждения манифест `update-<client>.json` публикуется на
   `https://plotina.cc/dl/`; с этого момента автообновление раздаёт новую версию.
6. Hotfix: тот же поток, но тег и манифест выпускаются сразу после проверки.

## Гейты (все обязательны)

- **Юнит-тесты**: `element-web/tests`, `element-desktop/tests`, `noise/tests`,
  `cinny/tests`, `fluffychat/tests`.
- **Патчи применяются** к запиненному upstream-тегу (для каждого клиента).
- **Артефакты десктопа**: control-поля Plotina, `app-update.yml` → `plotina-cc/clients`,
  иконка совпадает с `branding/icons`, asar-маркеры (266 fallback, модалка,
  `plotina-theme.js`, относительный фон), xz-сжатие control.
- **Артефакты Android**: `versionCode` строго больше предыдущего, подпись нашим
  ключом, package id ожидаемый, sha256 и размер совпадают с `update-<client>.json`,
  в пользовательских строках нет `vector-im`, `element.io`, `ko-fi`, `FluffyChat`,
  `Cinny`.
- **Публикация**: `/dl/<файл>` отдаётся 200 и байт-в-байт совпадает с артефактом,
  `update-<client>.json` ссылается на этот файл.
- **Установка**: deb ставится в чистом Debian-контейнере; AppImage запускается под
  Xvfb; APK ставится на тестовое устройство.

## TDD

- Сначала тест (или артефактная проверка), который падает, затем фикс.
- Для UI-багов — проверка на уровне артефакта (например, глиф в
  `ic_launcher_foreground` занимает 1/3 канваса), а не «посмотрел глазами».
- Патч к upstream без теста на применимость не принимается.

## Откат

- Android не разрешает понижение `versionCode`, поэтому откат = hotfix с большим
  номером, а не возврат старого APK.
- В манифесте можно поставить `"paused": true`, чтобы временно прекратить раздачу.
- Артефакты N-1 хранятся на `/dl` и в GitHub Releases; apt-репозиторий держит две
  последние версии.
